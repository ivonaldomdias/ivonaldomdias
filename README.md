## 📁 Featured projects

### 💰 finops-cloud-toolkit
FinOps toolkit to collect, analyze and visualize costs across multicloud environments. It detects idle resources (stopped EC2 instances, orphaned EBS volumes, instances with CPU < 5%) and generates an executive HTML report plus a consolidated CSV.

`Python` `AWS` `OCI` `FinOps`

### 📊 datadog-cost-datalake
Cost observability pipeline: Datadog → AWS S3 → Databricks Delta Lake. It collects Infrastructure, APM, Logs and estimated cost metrics through the API, stores them as partitioned Parquet and organizes the data in a Medallion architecture (Bronze → Silver → Gold). It detects anomalies with Z-Score and calculates month-over-month trends per product.

`Python` `Datadog` `S3` `Databricks`

### 🔐 cloud-security-scanner
Automated multicloud security scanner. It detects Security Groups with critical ports exposed (SSH, RDP, databases) to 0.0.0.0/0, instances running end-of-life operating systems and microservices with outdated runtimes. It generates a risk score (0–100) and an executive HTML report.

`Python` `AWS` `Security` · v2.0 roadmap: IAM overpermissions, public buckets and full CIS Benchmark
